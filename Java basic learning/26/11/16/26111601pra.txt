## 0 怎么用这本练习集

**核心原则：答案只在最后。** 先整段限时做完，再翻 §4 对答案；不要做一题看一眼答案，那样练不出考场手感。

### 0.1 三轮用法（照做，别跳步）

| 轮次 | 时间安排 | 做什么 | 过关标准 |

| 第 1 轮 · 摸底 | 60 分钟，一次做完 A 级 30 题（每题 1.5–2 分钟，超时就先猜一个标记） | 只看题面，不翻书不翻答案 | 对 ≥ 24 题算及格；把错题号抄进 §5 记录表 |

| 第 3 轮 · 二刷 | 考前一天 45 分钟 | 只做 §5 里「二刷未通过」的题号，重做 A 级错题 + 重写 B/C 错题的代码 | 错题全部能不看答案讲出为什么错 |

### 0.2 三条纪律

1. **A 级必须全对**。A 级考的都是「一眼看出来」的语义细节（`==` 和 `=`、`&&` 和 `&`、switch 贯穿、差一），这些在考卷上值 1–2 分的送分小题，错一个就是白丢分。
2. **B 级按「手写代码」的标准练**。开卷考试允许翻课件，但**时间只有 2 小时、只有 2 道大题**，翻书的时间必须省给调试。熟练度只能靠手打出来。
3. **错题必写原因**。§5 的表格里「错因」一栏不能写「粗心」「不会」——要写具体机制，例如「switch 的 case 2 后面漏了 break，贯穿到 case 3」。写不出机制，说明这题还没真懂，标成二刷重点。

### 0.3 关于代码环境

- 本集所有 Java 代码都用 `javac` / `java` **真实编译并运行过**，输出与 §4 的答案逐字一致（JDK 25 验证，语法只用 Java 7 就支持的写法，Eclipse 4.10 + JDK 11 可以原样跑）。
- 每个程序都是独立文件：文件名 = `public class` 的名字，例如 `B01.java` 里写 `public class B01`。
- 课上讲过 `Scanner` 就用 `Scanner` 版；**考试更可能是「把变量写死」**（题目直接给 `num1 = 17` 这种），所以涉及输入的题都**同时给了「硬编码变量版」**——两种都要会写。

### A09 【填空】[truth-table]

已知 `int num1 = 5, num2 = 7, num3 = 5;`，填出下面六个表达式的值（`true` 或 `false`）：

```java
num1 == 5 & num2 == 5      // (1)true
num1 == 5 & num3 == 5      // (2)true
num1 == 5 | num2 == 5      // (3)true
num1 == 5 | num3 == 5      // (4)true
num1 == 5 ^ num2 == 5      // (5)false
num1 == 5 ^ num3 == 5      // (6)false
```
